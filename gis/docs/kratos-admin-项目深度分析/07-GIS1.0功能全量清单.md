## TL;DR

- GIS1.0（"迈达云" maidacloud）是面向**燃气/水务/排污企业的地下管线 GIS + 物联网监测 + 巡检 + 工单 + 资产一体化平台**：Jeecg-Boot 二次开发单体（Spring Boot 2.1.3，约 150 个 Controller）+ Vue2/ElementUI/高德 AMap 前端 + MySQL 多库（base/gis/data/trail/prod/work 六库）。
- 最有价值的业务资产：**DMA 分区计量漏损分析**（分区设置/漏损六步向导/输差诊断/模拟分析）、管网监测多维分析、巡检闭环、报警/大屏。
- 核心技术债：单体巨石、Spring Boot 2.1.3/ fastjson/Shiro 存在已知 CVE、硬编码（绝对路径/内网 IP/默认密码）、**空间数据以 JSON 文本存储而非空间类型**、前端 demo/备份文件入库、dma/dmaWater 两套复制代码。

## 2. 后端模块（Maven 2 模块）

- `maida-boot-base-common`：通用底座（Shiro/JWT/Redis/工具/CommonController）。
- `maida-boot-module-system`：**单体巨石（约 150 个 Controller）**，按包划分业务域：
  - system/admin：Jeecg 原生 RBAC（用户/角色/权限/部门/字典/日志/公告/企业多租户）
  - gis/map：管网地图（/gis/pipe、/gis/overlay、/gisMap、/gis/area）
  - gis/equipment：设备台账/监测数据/巡检/工单（30+ Controller，最大域）
  - gis/patrol：巡检任务/计划/点位/隐患
  - gis/dev_maintain（维保）、gis/cad（CAD 底图）、gis/drive（采集网关/RTU）、gis/collect、acquisition（采集）、gis/code（二维码绑定）
  - prod/*：alarm（报警）、datav（大屏）、homepage（首页积木配置）、onduty（值班排班）、org（车队/仓库/物资/摄像头/SOS）、evidence（取证）
  - eam/*：asset（资产维保，含对接 GIS2 的 AssetGis2Controller）、purc（采购入库）、dict（品牌/供应商/类型）
  - workOrder、trail（轨迹）、message（WebSocket）、quartz、cas（单点登录）、foreign（第三方开放接口 /foreign/jurisdiction）

## 6. 与 GIS2.0 的演进关系

- GIS1.0（Jeecg 单体 + 高德 2D）与 GIS2.0（Spring Cloud 微服务 + Vue3）是"复制演进"两代，dma/dmaWater 整目录复制是其演进模式缩影（1.0 已有 `AssetGis2Controller` 对接 2.0）。
- 两代均为 SNOP 平台重建的溯源素材，权威功能口径见 04 号 F- 清单。

## 7. 技术债清单

1. 单体巨石：单模块约 150 Controller，业务边界全靠包名约定。
2. 安全：Spring Boot 2.1.3（EOL）、fastjson 1.2.83、Shiro 1.5.3 均有已知 CVE。
3. 硬编码：pom.xml systemPath 绝对路径、README 内网 IP、Druid admin/123456、MySQL root/root。
4. **空间数据 JSON 文本存储**，无空间索引，无法用 ST_* 分析。
5. 前端旧构建链（node-sass 4）+ demo/备份文件入库。
6. 菜单/权限深耦合 Jeecg sys_permission。
7. DMA 两套复制代码（dma/dmaWater），改动需双份同步。
